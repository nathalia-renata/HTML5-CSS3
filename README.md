# 🌐 HTML5 & CSS3: Desenvolvimento Web Front-End

## 📝 Descrição

Este repositório reúne minhas atividades, exercícios e projetos desenvolvidos com **HTML5** e **CSS3**. Ele documenta minha evolução no desenvolvimento web front-end, focando na criação de interfaces modernas, estruturação semântica de páginas e estilização responsiva para diferentes dispositivos.

## 🚀 Conteúdos e Tópicos Abordados

- **HTML5 Semântico:** Uso estruturado de tags semânticas (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`) visando acessibilidade e SEO.
- **Estilização com CSS3:** Manipulação de cores, tipografia, espaçamentos (box model), seletores e estilização de formulários e botões.
- **Layouts Modernos:**
  - **Flexbox:** Alinhamento, distribuição e organização de elementos unidimensionais.
  - **CSS Grid:** Construção de layouts bidimensionais complexos e adaptáveis.
- **Design Responsivo:** Aplicação de `@media queries` e unidades relativas (`rem`, `em`, `%`, `vw/vh`) para adaptação a smartphones, tablets e desktops.
- **Animações e Efeitos:** Transições (`transition`), animações com `@keyframes` e efeitos interativos (`:hover`, `:focus`, `:active`).
